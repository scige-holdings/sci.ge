# Changelog

All notable changes to the SCI.GE project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.0.0] - 2026-07-27

### Added
- Clean HTML5/CSS3 minimal infrastructure placeholder with Inter and Noto Sans Georgian fonts.
- Strict anti-indexation meta directives (`noindex, nofollow`).
- Open Graph metadata for rich previews in messaging apps.
- HTTPS enforcement configuration via Cloudflare Edge and GitHub Pages.
- Standard security.txt policy file placed under `.well-known/`.
- Custom `robots.txt` blocking automated web crawlers.

### Changed
- Standardized legal copy for corporate restructuring and domain reservation.
- Enhanced responsive mobile viewport scaling without blocking accessibility zoom.
- Converted email contacts to direct mailto links.

### Fixed
- Corrected Georgian text alignment (`text-align: left`) removing invalid RTL styles.
- Cleaned up invalid CSS comment syntax inside style blocks.
